# 📋 Task Manager - Контекст проекта для Cursor

## 🎯 ОПИСАНИЕ ПРОЕКТА

**Task Manager** - интерактивная доска планирования задач в стиле Kanban с возможностями drag-and-drop и real-time синхронизации. Предназначена для планирования спринтов с учетом емкости команд по направлениям: iOS, Android, QA, SA (Системный анализ).

---

## 🏗️ АРХИТЕКТУРА ПРОЕКТА

### Backend (FastAPI + SQLAlchemy)
```
backend/
├── app/
│   ├── __init__.py
│   ├── main.py                 # FastAPI приложение, WebSocket endpoint

│   │   ├── features.py        # CRUD фич, метаданные (МГМТ, Эпик, проект)
```

## 💾 БАЗА ДАННЫХ

### Переключение режимов
- **DEBUG=True** → async SQLite (`task_manager_debug.db`)
- **DEBUG=False** → PostgreSQL (asyncpg)

### Модели данных

#### Board (Доска)
- `id`, `name`, `created_at`
- **Автоматически создает 6 спринтов** при создании

#### Sprint (Спринт) - 6 штук на доску
- `id`, `board_id`, `number` (1-6)
- **Емкости по командам**: `capacity_ios`, `capacity_android`, `capacity_qa`, `capacity_sa`
- **Расширенные поля**: `description` (описание под названием)
- **Бейджи**: `badge1_text`, `badge1_color`, `badge1_tooltip`, `badge2_text`, `badge2_color`, `badge2_tooltip`

#### Feature (Фича/строка)
- `id`, `board_id`, `name`, `order` (для сортировки строк)
- **Метаданные**: `mgmt_link`, `mgmt_title`, `epic_link`, `epic_title`, `project_code`
- **Автоматическое извлечение названий** из URL (после последнего слеша)

#### Task (Задача/тикет)
- `id`, `feature_id`, `sprint_id`, `name`, `color`
- **Оценки**: `estimate_ios`, `estimate_android`, `estimate_qa`, `estimate_sa`
- **Позиция**: `position_x`, `position_y`
- **Энейблер**: `enabler_title`, `enabler_active` (всегда True)
- **Сворачивание**: `is_collapsed_feature`, `original_feature_tasks` (JSON)

#### History (История для Undo/Redo)
- `id`, `board_id`, `action_type`, `data` (JSON), `timestamp`

## 🚨 ЧАСТЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ

### 1. Дублирование тикетов
**Причина**: Неправильная очистка массивов при обновлении
**Решение**: Используйте `filter(t => t.id !== taskId)` перед добавлением

### 2. Рассинхронизация ширины столбцов
**Причина**: CSS Grid ячеек не синхронизирован с заголовками
**Решение**: `calculateSprintWidths()` + применение `gridTemplateColumns` ко всем строкам

### 3. Тикеты попадают в backlog при редактировании
**Причина**: Не сохраняется оригинальный `sprint_id`
**Решение**: `sprint_id: isEdit ? currentTask.sprint_id : null`

### 4. Не сохраняется порядок строк
**Причина**: Обновляется только одна фича
**Решение**: Обновление `order` для всех фичей по новому порядку DOM

## 📡 API ENDPOINTS

### Базовые операции
- `GET/POST /api/boards/` → CRUD досок (POST автосоздает 6 спринтов)
- `GET/PUT /api/sprints/{id}` → получение/обновление спринта
- `GET/PUT /api/features/{id}` → получение/обновление фичи  
- `GET/POST/PUT/DELETE /api/tasks/{id}` → полный CRUD задач

### Специальные endpoints
- `POST /api/tasks/move` → перемещение тикетов с историей
- `GET /api/sprints/{id}/capacity` → расчет емкости спринта
- `GET /api/tasks/?sprint_id=X` → задачи спринта
- `GET /api/tasks/unassigned/{board_id}` → задачи backlog

### Важные детали API
- **Все ответы dict**, не Pydantic схемы (для упрощения)
- **Автоматические поля**: `created_at`, `updated_at`
- **JSON поля**: `original_feature_tasks` для сворачивания

## 🎯 БУДУЩИЕ ЗАДАЧИ - ПОДСКАЗКИ

### При добавлении новых полей в модели:
1. Обновить `models.py` → добавить Column
2. Обновить `schemas.py` → добавить в Base/Create/Update
3. Обновить роутеры → добавить поля в ответы
4. **Пересоздать БД**: удалить `task_manager_debug.db` и перезапустить
5. Обновить JavaScript рендеринг

### При проблемах с многорядностью:
1. Проверить `calculateSprintWidths()` 
2. Убедиться что `gridTemplateColumns` применяется ко всем строкам
3. Проверить CSS: `grid-template-rows: repeat(5, auto)`
4. Отладить через console.log в `renderTasksInCell()`

### При проблемах с сохранением:
1. Проверить отладочные логи: `debugTaskDistribution()`
2. Убедиться в очистке дубликатов: `filter(t => t.id !== taskId)`
3. Проверить логику `positionChanged` в `updateTaskOnBoard()`

### При добавлении новых API:
1. **Использовать dict**, не Pydantic схемы
2. Добавить обработку ошибок
3. **НЕ добавлять** уведомления об успехе
4. Обновить JavaScript API клиент
